Cómo funciona nxt-python

El programa en Python corre en la computadora y le envía órdenes al NXT por USB (o Bluetooth), una por una. Es distinto de leJOS, donde el programa se copia al NXT y corre dentro de él.

leJOS (Java)nxt-python
Dónde corre el programaEn el NXTEn la computadora
Firmware del NXTleJOS (hay que instalarlo)El original de LEGO (no se toca)
Sirve también para Open RobertaNo, hasta reinstalar el de LEGOSí
Robot sin cableSí, una vez subido el programaSolo con Bluetooth
Pantalla del NXTSe usa para mostrar mensajesLos mensajes salen en la computadora

Es una buena opción para trabajar robótica en Python con los NXT de la sala sin cambiarles el firmware, en paralelo con lo que se hace con Python en el SPIKE.

↑ índiceInstalación (Ubuntu)

01

Comprobar el firmware del NXT

nxt-python necesita el firmware original de LEGO. Encender el NXT: si aparece el menú de LEGO (My Files, NXT Program, View…), está listo. Si aparece el menú de leJOS, ese NXT se usa con Java o hay que reinstalarle el firmware de LEGO con el software LEGO MINDSTORMS NXT.

Configurar el apagado automático para que no se apague durante la clase: en el menú de LEGO, Settings → Sleep → Never.

02

Instalar Python y nxt-python

En Ubuntu, los paquetes de Python se instalan dentro de un entorno virtual (una carpeta con su propio Python). En una terminal:

Terminal
sudo apt update
sudo apt install python3-venv python3-pip libusb-1.0-0

python3 -m venv ~/nxt-env
source ~/nxt-env/bin/activate
pip install --upgrade nxt-python

Cada vez que se abra una terminal nueva para trabajar con el NXT, activar el entorno con source ~/nxt-env/bin/activate. Se nota porque aparece (nxt-env) al principio de la línea.

03

Dar permiso de acceso al NXT por USB

Si la computadora ya tiene la regla de la guía de leJOS en Linux (repositorio NXT-java), este paso no hace falta. Si no:

Terminal
sudo tee /etc/udev/rules.d/70-lego-nxt.rules > /dev/null <<'EOF'
SUBSYSTEM=="usb", ATTRS{idVendor}=="0694", ATTRS{idProduct}=="0002", MODE="0666"
EOF

sudo udevadm control --reload-rules
sudo udevadm trigger

Desconectar y volver a conectar el NXT.

04

Probar la conexión

Con el NXT encendido, conectado por USB y el entorno activado:

Terminal
nxt-test

Si encuentra el NXT, muestra su nombre, la versión del firmware y el nivel de batería, y emite un sonido.

Opcional · Bluetooth

Para conectar sin cable, instalar el soporte de Bluetooth con sudo apt install python3-bluez y emparejar el NXT (PIN 1234). Requiere que la computadora tenga Bluetooth.

05

Primer programa

Crear una carpeta para los programas, por ejemplo ~/nxt-python, y dentro el archivo hola.py:

hola.py
import nxt.locator

# buscar el NXT conectado
with nxt.locator.find() as b:
    nombre = b.get_device_info()[0]
    print("Conectado a:", nombre)
    b.play_tone(440, 250)
Terminal
cd ~/nxt-python
python hola.py

Todo lo que el robot hace ocurre dentro del bloque with: al salir de él, la conexión se cierra. El programa corre en la computadora y envía órdenes al NXT, así que el cable tiene que quedar conectado mientras el programa funciona.

Con VS Code

Instalar la extensión Python (Microsoft), abrir la carpeta, presionar Ctrl + Shift + P → Python: Select Interpreter y elegir ~/nxt-env/bin/python. Después se ejecuta con el botón ▶ de la esquina superior derecha.

06

Motores

La potencia va de −100 a 100 (negativa: hacia atrás). Motor izquierdo en B y derecho en C.

motores.py
import time
import nxt.locator
import nxt.motor

with nxt.locator.find() as b:
    izquierdo = b.get_motor(nxt.motor.Port.B)
    derecho = b.get_motor(nxt.motor.Port.C)

    # girar una cantidad de grados (potencia, grados)
    izquierdo.turn(70, 360)
    derecho.turn(70, 360)

    # los dos motores sincronizados: avanzan en linea recta
    ambos = nxt.motor.SynchronizedMotors(izquierdo, derecho, 0)
    ambos.turn(70, 720)

    # por tiempo: arrancar, esperar y frenar
    izquierdo.run(70)
    derecho.run(70)
    time.sleep(2)
    izquierdo.brake()
    derecho.brake()
MétodoQué hace
turn(potencia, grados)Gira esa cantidad de grados y espera a terminar.
run(potencia)Gira sin parar.
brake() / idle()Frena de golpe / deja el motor suelto.
SynchronizedMotors(a, b, giro)Mueve dos motores juntos; con giro 0 van en línea recta.
07

Sensores

El sensor ultrasónico se detecta solo. Los demás (contacto, luz, sonido) son analógicos y hay que indicar su clase.

sensores.py
import time
import nxt.locator
import nxt.sensor
import nxt.sensor.generic

with nxt.locator.find() as b:
    tacto = b.get_sensor(nxt.sensor.Port.S1, nxt.sensor.generic.Touch)
    luz = b.get_sensor(nxt.sensor.Port.S3, nxt.sensor.generic.Light)
    sonar = b.get_sensor(nxt.sensor.Port.S4)
    luz.set_illuminated(True)

    print("Ctrl + C para terminar")
    while True:
        print("Tacto:", tacto.get_sample(),
              "Luz:", luz.get_sample(),
              "Distancia:", sonar.get_sample(), "cm")
        time.sleep(0.5)

Los valores se muestran en la terminal de la computadora, no en la pantalla del NXT. El programa se detiene con Ctrl + C.

08

Explorador que esquiva obstáculos

explorador.py
import time
import nxt.locator
import nxt.motor
import nxt.sensor
import nxt.sensor.generic

with nxt.locator.find() as b:
    izquierdo = b.get_motor(nxt.motor.Port.B)
    derecho = b.get_motor(nxt.motor.Port.C)
    sonar = b.get_sensor(nxt.sensor.Port.S4)

    try:
        while True:
            if sonar.get_sample() < 25:
                izquierdo.brake()
                derecho.brake()
                b.play_tone(880, 200)
                izquierdo.turn(60, 360)      # girar en el lugar
                derecho.turn(-60, 360)
            else:
                izquierdo.run(70)
                derecho.run(70)
            time.sleep(0.1)
    except KeyboardInterrupt:
        print("Fin")
    finally:
        # pase lo que pase, frenar los motores al terminar
        izquierdo.brake()
        derecho.brake()

try / finally asegura que los motores se detengan aunque el programa se corte con Ctrl + C.

09

Una clase Robot en Python

La misma idea de la clase auxiliar de Java, ahora como una clase con atributos (self.izquierdo, self.sonar) y métodos. Permite comparar POO en los dos lenguajes.

robot.py
import nxt.motor
import nxt.sensor
import nxt.sensor.generic


class Robot:
    def __init__(self, brick):
        self.brick = brick
        self.izquierdo = brick.get_motor(nxt.motor.Port.B)
        self.derecho = brick.get_motor(nxt.motor.Port.C)
        self.ambos = nxt.motor.SynchronizedMotors(self.izquierdo, self.derecho, 0)
        self.tacto = brick.get_sensor(nxt.sensor.Port.S1, nxt.sensor.generic.Touch)
        self.sonar = brick.get_sensor(nxt.sensor.Port.S4)

    def avanzar(self, grados, potencia=70):
        self.ambos.turn(potencia, grados)

    def girar_derecha(self, grados, potencia=60):
        self.izquierdo.turn(potencia, grados)
        self.derecho.turn(-potencia, grados)

    def distancia(self):
        return self.sonar.get_sample()

    def choco(self):
        return self.tacto.get_sample()

    def pitar(self):
        self.brick.play_tone(440, 200)
cuadrado.py
import nxt.locator
from robot import Robot

with nxt.locator.find() as b:
    r = Robot(b)
    for lado in range(4):
        r.avanzar(720)
        r.girar_derecha(180)     # ajustar hasta lograr 90 grados
    r.pitar()

Los dos archivos tienen que estar en la misma carpeta. Comparado con Java: __init__ cumple el papel del constructor, y self el de this.

Windows

¿Y en Windows?

nxt-python funciona en Windows, pero necesita la librería libusb y, en muchos casos, reemplazar el driver USB del NXT con la herramienta Zadig. Ese cambio afecta a los demás programas que usan el NXT por USB en esa computadora (por ejemplo, el driver Fantom), y revertirlo no es simple. Por eso, en las Ceibalitas no se recomienda: conviene usar nxt-python desde Ubuntu.

Problemas frecuentes

Si algo no funciona

«No module named 'nxt'»
El entorno virtual no está activado: ejecutar source ~/nxt-env/bin/activate (o elegir el intérprete correcto en VS Code).
«No brick found» / BrickNotFoundError
Revisar que el NXT esté encendido, con el firmware de LEGO, conectado por USB, y que exista la regla de permisos. Probar con nxt-test.
«Access denied» o error de permisos USB
Revisar la regla udev, desconectar y volver a conectar el NXT.
El NXT se apaga solo
Configurar Settings → Sleep → Never en el menú del NXT.
El robot sigue andando después de cortar el programa
Usar try / finally para frenar los motores al terminar, como en el ejemplo del explorador.
